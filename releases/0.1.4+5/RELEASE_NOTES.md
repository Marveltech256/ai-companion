# Ai Companion 0.1.4 (5) — Internal testing

Extends the existing onboarding and Settings using the approved visual language.
Choose a companion name, one or two personalities, up to four optional support
areas, communication style and optional learning interests/goals/additional
details. Current preferences persist in the owned Supabase companion row and
shape welcomes and later replies alongside existing memory and history.
Existing accounts retain their setup, data and consent.

The update does not activate purchases, scheduled AI delivery, real-time calling
or younger-user access. Gemini remains restricted to the current adult release;
the requested youth experience needs an eligible provider, consent and validated
safeguarding before launch. European AI testing remains pending paid API setup.
See the current [enhancement record](../../docs/personalized-onboarding.md) and
[internal-test guide](../../docs/internal-testing.md).

Six actual synthetic adult replies passed named greetings, restored preferences,
goal continuity and selected French language. Three temporary adult identities
were erased afterward. This is a bounded smoke check, not evidence of universal
response quality, child safety or physical-device readiness.

Use the new version-code-5 signed bundle for subsequent testing uploads. Reuse
the existing upload key; retain all earlier artifacts. Nothing here publishes a
Play release. Play-signed Google login, physical audio/accessibility checks and
broader longitudinal quality remain acceptance work.
