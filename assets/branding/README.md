# Ai Companion branding

The source is the user-provided `Ai companion logo .png` (713×587), copied byte-for-byte as `logo-original.png`.

SHA-256: `743DDC465F47E767E6F89C90FC688E4CC803F4BD12A538B766DA31FEC2201382`

`tools/prepare_branding.ps1` produces standard platform icon sizes from this original mark, keeping its proportions and colours. Only the surrounding white margin is fitted to each icon canvas; the original remains unchanged. The in-app mark and iOS/legacy/web icons use white backgrounds. Android adaptive foreground and web maskable variants have padding for their safe areas.

The approved companion orb remains the companion avatar. The supplied logo identifies the application in the wordmark and platform launcher/browser icons. Firebase registrations, database object names, installed application IDs, and saved-data keys remain stable across the rebrand.
